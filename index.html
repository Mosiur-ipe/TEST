🎓 About T.E.S.T
📖
What is T.E.S.T?

T.E.S.T — Technical Exam Support Toolkit — is a free platform built for Industrial & Production Engineering (IPE) students across universities in Bangladesh. We organize previous year term-final exam questions by course and topic, complete with solutions, reference book sources, and lab facility directories.

Whether you study IPE at BUET, RUET, KUET, CUET, SUST or any other university offering the degree in Bangladesh, T.E.S.T helps you find exactly the resources you need — fast and for free.

🎯
Our Mission

To make academic learning accessible through reliable resources, previous year questions, and trusted explanations — helping students learn with clarity and confidence.

🔭
Our Vision

To create a global student learning platform where learners across disciplines can access quality resources, understand complex concepts more easily, and grow through shared knowledge — beyond exams, beyond institutions, and beyond borders.

🔐 One-Time Firebase Setup Required

Your Firestore Security Rules are blocking uploads and deletes. This is a one-time fix — paste the rules below into your Firebase Console and publish. You will never need to do this again. 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Questions — anyone can read; logged-in users can create;
    // only the uploader can update or delete their own question.
    match /questions/{docId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null
                            && request.auth.uid == resource.data.uploaderUid;
    }

    // Users — each user can only read/write their own profile.
    match /users/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }

  }
}
📋 Steps to fix (takes 30 seconds)
  1. Copy the rules above
  2. Go to Firebase Console → Firestore → Rules
  3. Select all existing text and paste the copied rules
  4. Click Publish
  5. Done — uploads and deletes will work instantly ✅
🗂️ Also Required: Firestore Composite Index
For questions to load correctly, create a composite index in Firebase Console → Firestore → Indexes:
Collection: questions
Fields: dept (Asc) · university (Asc) · courseCode (Asc)
